# 善达企业知识助手

面向企业员工的知识问答入口，支持查看回答引用、核对来源和反馈问题。

## 在线访问

- **善达企业知识助手**：[http://assit.quickdone.cn/](http://assit.quickdone.cn/)
- **善达知枢（管理端）**：[http://manager.assit.quickdone.cn/](http://manager.assit.quickdone.cn/)

## 使用文档

- [企业知识助手使用手册](https://chif-1980.github.io/sdkb/guide/knowledge-assistant.html)
- [善达知枢使用手册](https://chif-1980.github.io/sdkb/guide/zhishu-manual.html)

## 0.6.0（2026-09-19）

完善会议待办编辑、忽略、逐条确认及飞书通知和任务同步；支持正式知识比对、历史会议搜索分页与版本选择、依据定位。优化已归档抽屉、后台任务和会话切换，配套善达知枢 0.6.0 会议管理与飞书统一身份。

## v0.5.1（2026-09-18）

优化会议跟进的后台任务展示、会话切换和未保存提示；完善企业成员选择、日期控件及会议纪要结果的交互反馈。

## v0.5.0（2026-09-18）

新增会议纪要跟进：上传者自动成为跟进负责人，行动项可关联当前飞书企业成员并维护期限与状态；知识更新建议交由知识维护人员处理，并保留会议结果版本控制。后端模型统一由善达知枢的模型供应商页面配置。
