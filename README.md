# 善达企业知识助手

面向企业员工的知识助手，支持正式知识问答、`@查资料`、`@做方案` 和 `@会议纪要`，通过来源依据核对回答，并将会议行动项转为可跟进的飞书待办。

## 主要功能与使用入口

| 功能 | 使用方式 |
| --- | --- |
| 知识问答 | 直接提问，回答基于有权限访问的正式知识，点击引用核对原文 |
| 查资料 | 输入 `@查资料`，补充名称、资料类型和用途，查找现成材料 |
| 做方案 | 输入 `@做方案`，补充需求和约束，核对并保存方案草稿 |
| 会议纪要 | 输入 `@会议纪要`，提供链接、文字或转写文件；兼容旧称 `@分析会议` |
| 会议跟进 | 在结果卡片补充、修改或忽略待办，从飞书企业通讯录选择负责人后逐条确认发送 |
| 后台任务与归档 | 左侧栏底部查看后台进度和已归档会话；会议后台处理期间可新建或切换会话 |

会议分享页读取有访问和完整性限制；需要登录、正文不全或解析失败时，按提示上传转写文件或粘贴正文。历史会议需主动选择，支持搜索、预览与分析版本选择，一次最多引用 5 场。

纪要支持“手动编辑”（直接修改标题、类型和正文，自动保存）和“AI 帮我修改”（输入修改要求后发送）。行动清单与待办统一为纪要中的“待办事项”，展开每条即可核对、修改和确认发送。复制与导出读取已保存待办；AI 对已有待办的修改先待核对，采用后仍需显式同步飞书。

原文含完整、有效的年月日时，待办日期框会自动带入并保留原文供核对；人工修改或清空后不会再次自动填回。日历中今天之前的日期置灰且不可新选，已有历史期限仍保留。

已发送待办分配有误时，点击“修改”，保存后“同步修改到飞书”，更新原任务；“已确认”与飞书通知、任务同步状态分别展示。知识更新建议逐条展示正式知识比对结果，由具有管理权限的知识维护人员在知枢 **会议管理 → 知识更新建议** 统一处理。

## 配套服务与配置

本仓库为企业知识助手前端，配套 [善达知枢 0.6.2](https://github.com/chif-1980/sdkb/tree/0.6.2) 的共享后端使用。模型接口、凭据及模型用途统一在知枢 **智能体管理 → 模型供应商** 配置，无需在助手前端填写模型密钥。

两端共用飞书身份；知枢管理权限单独授予。知识访问授权和任务通知权限由管理员按实际部署配置。详见[模型配置](https://chif-1980.github.io/sdkb/intro/model-config.html)和[部署说明](https://chif-1980.github.io/sdkb/advanced/deployment.html)。GitHub 版本更新不代表服务器已同步部署。

## 本地原型的稳定性加固

以下审计接口属于仓库保留的本地 Fastify 原型；生产共享后端的会议审计在知枢“会议管理 → 处理记录”查看。

- 正式知识回答只使用主来源存在、已完成处理且不是会话临时资料的知识；来源不完整时返回依据不足，不生成无来源正文。
- 资料创建、处理成功或失败、转为正式资料，知识审核和重建索引，会话创建、问答、归档、恢复，以及身份切换都会写入审计记录。
- 管理员可通过 `GET /api/audit-logs` 按操作、资源、结果和时间范围查询审计记录；日志不保存正文、凭据或访问令牌。
- 会议待办和飞书通知、任务状态回读继续以配套远程服务为准；本仓库保留任务来源、负责人、期限、通知、任务 ID、同步状态和失败原因等契约字段，生产发布前需验证幂等发送、日期时区和状态回读。
